# Smileworx Dental Care Website

Official website for **Smileworx Dental Care** (ஸ்மைல்ஒர்க்ஸ் பல் மருத்துவமனை), located in Ponniammanmedu, Chennai, led by Dental Surgeon **Dr. S. Helen Joice**.

Built with pure **HTML5, CSS3, and Vanilla JavaScript** for maximum portability, zero build dependencies, and instant local execution (`file:///`) or static hosting (GitHub Pages, Netlify, Vercel).

## Website Architecture & Pages

1. **Home (`index.html`):** Hero presentation, clinical specialties overview, interactive before & after porcelain veneers slider, doctor bio, and clinic timings.
2. **About (`about.html`):** Practice philosophy, neighborhood healthcare roots in North Chennai, Dr. S. Helen Joice credentials, and hospital-grade sterilization protocols.
3. **Treatments (`treatments.html`):** Detailed guides for the 6 core clinical disciplines:
   * Orthodontic Braces (பல் வரிசைப் படுத்துதல்)
   * Clear Aligners (அலைனர்ஸ்)
   * Dental Implants (இம்ப்ளான்ட்ஸ்)
   * Custom Dentures (செயற்கை பல்செட்)
   * Veneers & Crowns

4. **Contacts (`contact.html`):** Direct phone call links, WhatsApp chat integration, consulting hours, address with 1-click clipboard copy, and interactive Google Maps.
